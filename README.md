# FreeCompile

A free browser-based coding studio from FreeToolz. Built with React and Vite for deployment on Vercel.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The initial workspace provides an interactive web playground, language switcher, local editor state, preview, JSON validation, and GitHub repository inspection entry point. Full repository execution uses browser runtime support and is progressively enabled only where the runtime is available.
